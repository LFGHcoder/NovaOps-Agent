🚀 NovaOps Agent
Multi-Agent AI System for Automating the Hiring Pipeline

NovaOps Agent is a prototype system that demonstrates how AI agents can coordinate to automate parts of the recruiting workflow.

Instead of recruiters manually reviewing resumes, writing interview questions, evaluating candidates, and updating hiring systems, NovaOps orchestrates multiple AI agents that work together to analyze candidates and produce a hiring recommendation.

This project was built for the Amazon Nova AI Hackathon and uses Amazon Nova models through Amazon Bedrock to power reasoning across the pipeline.

🎯 The Problem

Recruiting pipelines involve repetitive tasks:

Resume screening

Interview preparation

Candidate evaluation

ATS updates

Hiring recommendations

These steps are often manual, inconsistent, and time-consuming.

NovaOps explores how AI agents can collaborate to automate large parts of this workflow.

⚙️ What NovaOps Agent Does

NovaOps takes a job description and candidate resume and processes them through a multi-agent AI pipeline.

The system:

• Reads the job description and generates an interview plan
• Screens the candidate’s resume against the role
• Simulates a technical screening interview
• Evaluates the candidate’s answers
• Simulates ATS workflow actions
• Produces a final hiring recommendation

The final output is a structured hiring report summarizing the candidate evaluation.

Example result:

{
  "candidate": "Alice Johnson",
  "overall_score": 78,
  "recommendation": "Shortlist",
  "status": "completed"
}
🧠 Multi-Agent Architecture

NovaOps is designed as a coordinated AI agent pipeline, where each agent performs a specific role in the hiring workflow.

Planner Agent
      ↓
Screening Agent
      ↓
Interview Agent
      ↓
Evaluation Agent
      ↓
Execution Agent
      ↓
Verification Agent
🤖 Agent Responsibilities
🧭 Planner Agent

Analyzes the job description and generates:

Required skills

Interview questions

Evaluation criteria

Workflow plan

📄 Screening Agent

Compares the candidate resume with the job description and produces a screening score.

🎤 Interview Agent

Simulates a short technical screening interview using questions generated by the Planner Agent.

📊 Evaluation Agent

Analyzes candidate responses and calculates a final evaluation score.

⚙️ Execution Agent

Simulates actions that normally occur in an Applicant Tracking System (ATS).

Examples:

Candidate status update

Hiring workflow progression

✅ Verification Agent

Ensures the entire pipeline executed successfully and returns the final structured result.

🔮 Future Work

The next stage of NovaOps is building a fully automated AI Interviewer.

Instead of only analyzing resumes, the system will conduct a structured screening interview with candidates.

The interview will include:

Behavioral Questions — 5 minutes
Evaluate communication and past experience.

Cultural Fit Questions — 5 minutes
Assess alignment with company values.

Technical Questions — 5 minutes
Test job-specific knowledge and reasoning.

The AI will evaluate:

How candidates structure answers

Communication clarity

Problem-solving reasoning

Alignment with job requirements

This could automate the first round of interviews, helping companies screen candidates faster and more consistently.
